# /perf — Performance Optimization

1. Identify performance bottlenecks (profiling, benchmarks)
2. Measure baseline metrics
3. Propose optimizations with expected impact
4. Implement (one change at a time)
5. Re-measure and compare against baseline
6. Report: before/after metrics, changes made
