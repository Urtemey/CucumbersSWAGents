# /quick — Quick Change

For small changes that don't need the full /new-feature pipeline.

1. Understand the change
2. Find relevant file(s)
3. Make the change
4. Run lint/typecheck
5. Show diff, offer to commit

If the change seems too large, suggest `/new-feature` instead.
