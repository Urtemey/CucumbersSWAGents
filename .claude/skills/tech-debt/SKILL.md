# /tech-debt — Technical Debt Management

1. Scan codebase for debt indicators:
   - TODO/FIXME/HACK comments
   - Duplicated code
   - Complex functions (high cyclomatic complexity)
   - Missing tests
   - Outdated dependencies
2. Categorize and prioritize findings
3. Propose remediation plan
4. Address items by priority (with approval)
