# /retro — Retrospective

Analyze a completed feature or sprint to extract lessons learned.

### Step 1: Gather Data
1. Read execution reports
2. Review git history and PRs
3. Check skill health metrics
4. Review any RCA documents created

### Step 2: Analyze
- What went well?
- What went poorly?
- What was surprising?
- What should we do differently?

### Step 3: Report
```
## Retrospective: [Feature/Sprint Name]

### What Went Well
- Item 1
- Item 2

### What Didn't Go Well
- Item 1 — root cause — suggested improvement

### Surprises
- Unexpected finding or outcome

### Action Items
- [ ] Action 1 — owner — deadline
- [ ] Action 2 — owner — deadline
```

### Step 4: Apply
Suggest updates to CLAUDE.md, skills, or agents based on findings.
