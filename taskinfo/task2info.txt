Human-in-the-loop (interrupt / resume)
Практическое задание: кастомное прерывание (Human-in-the-loop) в LangGraph
Цель
Реализовать граф на LangGraph, в котором один узел запрашивает подтверждение у пользователя через кастомное прерывание: в прерывание передаётся структурированный объект (тип, вопрос, варианты ответа). Цикл запуска графа обрабатывает это прерывание: показывает вопрос в консоли (например, через меню выбора), получает ответ и возобновляет выполнение графа. В итоге вы получите работающий поток с одной «остановкой» для ввода человека и продолжением после ответа.

Стек и установка
Python 3.10+
langgraph — граф с поддержкой прерываний и чекпоинтов
questionary — интерактивный выбор в консоли (или аналог на ваш вкус)
Установка:

pip install langgraph questionary
При необходимости добавьте зависимости из вашего проекта (например langchain, langchain-openai), если будете расширять граф.

Что нужно сделать
Состояние графа
Опишите состояние (например через TypedDict): как минимум поле для значения, которое позже заполнит пользователь (например human_value), и при необходимости ещё одно поле (например foo) для начальных данных.

Узел с прерыванием
Добавьте один узел, который вызывает interrupt(...) из langgraph.types, передавая словарь с полями:

тип прерывания (например "alert" или "confirm");
текст вопроса (например «Уверены, что хотите продолжить?»);
список допустимых ответов (например ["approve", "reject"]).
После возобновления прерывания результат придёт в узел — сохраните ответ пользователя в состоянии (например в human_value) и верните обновлённое состояние.
Сборка графа
Соберите граф: один узел, переход из START в этот узел. Скомпилируйте граф с чекпоинтером (InMemorySaver из langgraph.checkpoint.memory), чтобы можно было возобновлять выполнение после прерывания.

Цикл запуска с обработкой прерывания
Запускайте граф через stream(...) с конфигом (например configurable={"thread_id": ...}). В цикле по чанкам:

если в чанке есть ключ __interrupt__, извлеките значение прерывания (payload, который вы передали в interrupt(...));
по этому payload покажите пользователю вопрос и варианты ответа (например через questionary.select) и получите выбранный ответ;
запишите ответ в тот же объект (например в поле answer) и возобновите граф, передав в graph.stream() объект Command(resume=...) с этим значением, с тем же config;
обработайте следующий поток чанков до конца.
Проверка
Убедитесь, что после выбора варианта граф продолжает работу и в состоянии появляется выбранное пользователем значение (например вывод в консоль обновлённого состояния).

Подсказки
Импорты: понадобятся StateGraph, START, interrupt, Command, InMemorySaver (из модулей langgraph.graph, langgraph.constants, langgraph.types, langgraph.checkpoint.memory) и библиотека для интерактивного ввода в консоли.

Узел: функция узла вызывает interrupt(ваш_словарь). Пока граф не возобновят, выполнение из узла не вернётся. После вызова graph.stream(Command(resume=...), config) в узел «вернётся» тот же объект, который вы передали в resume — добавьте в него поле с ответом пользователя и по этому полю сформируйте возвращаемое состояние.

Структура чанка при прерывании: ключ __interrupt__ ведёт к списку; у первого элемента есть атрибут .value — это тот самый словарь, который вы передали в interrupt(...). Его можно менять (добавить поле с ответом) и затем передать в Command(resume=...).

Возобновление: второй вызов graph.stream(...) принимает первым аргументом не начальное состояние, а Command(resume=обновлённый_payload); конфиг должен быть тот же (тот же thread_id), иначе чекпоинт не подхватит контекст.

Ожидаемый результат
При запуске граф доходит до прерывания; в консоли появляется сообщение о остановке и/или вопрос.
После выбора варианта (например approve или reject) выполнение продолжается.
В выводе видно обновлённое состояние узла с выбранным значением, например:
Произошла остановка
{'type': 'alert', 'question': 'Уверены что хотите продолжить?', 'allow_responds': ['approve', 'reject']}
!!! alert !!!
> Received an input from the interrupt: approve
{'node': {'human_value': 'approve'}}
(Точный текст может отличаться в зависимости от ваших формулировок.)

Критерии оценки
| Критерий | Баллы | |----------|-------| | Состояние графа задано, узел возвращает обновлённое состояние после прерывания | 2 | | В узле вызывается interrupt() с объектом (вопрос + варианты ответа) | 2 | | Граф собран с чекпоинтером и успешно компилируется | 2 | | В цикле по чанкам обрабатывается __interrupt__, показывается вопрос и получается ответ пользователя | 2 | | Граф возобновляется через Command(resume=...), выполнение доходит до конца и выводится итоговое состояние | 2 | | Итого | 10 |
