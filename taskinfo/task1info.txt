Создайть просто AI агент на Python с применением langchain
Практическое задание: AI-агент на LangChain
Цель
Написать Python-скрипт, реализующий иерархического AI-агента с использованием библиотеки LangChain и локальной языковой модели.

Контекст
AI-агент — это языковая модель, которая умеет вызывать инструменты (функции) и принимать решения о том, какой инструмент использовать для ответа на вопрос пользователя.

Иерархический агент — это агент, у которого один из инструментов сам является агентом. Такой подход позволяет декомпозировать сложные задачи.

Стек
Python 3.10+
LangChain — фреймворк для построения агентов
LM Studio — локальный сервер языковых моделей (поднимается на http://localhost:1234)
Установка зависимостей
pip install langchain==1.2.10 langchain-openai==1.1.9
Задание
Реализуй агента-помощника по планированию списка покупок. Агент должен уметь:

Принимать от пользователя список продуктов
Для каждого продукта узнавать примерную цену (через отдельный субагент)
Считать итоговую стоимость корзины
Требования к реализации
1. Подключение к модели
Подключись к локальной LLM через OpenAI-совместимый API:

from langchain_openai import ChatOpenAI
from pydantic import SecretStr

llm = ChatOpenAI(
    model='<название модели в LM Studio>',
    base_url='http://localhost:1234/v1',
    api_key=SecretStr('fake'),
    temperature=0.7,
)
2. Инструмент с субагентом
Создай инструмент get_price(product: str, city: str) -> str с декоратором @tool.

Внутри инструмента создай субагента (create_agent), который будет генерировать реалистичную цену на продукт в указанном городе, опираясь на исторические данные о ценах. Субагент должен возвращать ответ в виде таблицы:

| Продукт | Цена (руб.) | Магазин |
3. Главный агент
Создай главного агента с системным промптом 'Ты помощник по планированию покупок', передай ему инструмент get_price.

4. Запрос и вывод
Задай агенту вопрос в духе:

Помоги составить список покупок: молоко, хлеб, яблоки. Я нахожусь в Казани.
Выведи все сообщения из ответа — как промежуточные вызовы инструментов, так и финальный ответ агента.

Подсказки
Создание агента
from langchain.agents import create_agent

agent = create_agent(
    model=llm,
    tools=[my_tool],           # список инструментов (опционально)
    system_prompt='...',
)
Вызов агента
answer = agent.invoke({
    "messages": [
        {"role": "human", "content": "твой вопрос"}
    ]
})
Результат — словарь с ключом messages. Последнее сообщение (answer['messages'][-1].content) содержит финальный ответ.

Декоратор @tool
from langchain.tools import tool

@tool
def my_tool(param: str) -> str:
    """Описание инструмента — модель читает его, чтобы понять, когда вызывать инструмент."""
    ...
    return result
Вывод цепочки сообщений
Каждое сообщение может быть либо текстом (message.content), либо вызовом инструмента (message.tool_calls). Пример функции форматирования:

def format_message(message) -> str:
    if message.content:
        return message.content
    return f"{message.tool_calls[0]['name']}({message.tool_calls[0]['args']})"
Ожидаемый результат
При запуске скрипта в консоли должна появиться цепочка вроде:

get_price({'product': 'молоко', 'city': 'Казань'})
get_price({'product': 'хлеб', 'city': 'Казань'})
get_price({'product': 'яблоки', 'city': 'Казань'})
